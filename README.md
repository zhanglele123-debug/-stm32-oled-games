# STM32 OLED Game Hub

基于 STM32F103C8 的 OLED 游戏大厅，128x64 I2C OLED 屏幕，四款可玩游戏。

## 硬件

| 组件 | 说明 |
|------|------|
| MCU | STM32F103C8 (Cortex-M3, 72MHz, 64K Flash, 20K RAM) |
| 屏幕 | 0.96" OLED 128x64 (SSD1306, I2C 地址 0x78) |
| 按键 | 4 个轻触开关 K1-K4 (PB12-PB15, 上拉输入) |

## 游戏

| # | 游戏 | 方向 | 说明 |
|---|------|------|------|
| 1 | **飞机大战** | 竖屏 | 经典射击，敌机生成/子弹/爆炸特效，难度递增，最高分记录 |
| 2 | **迷宫** | 横屏 | DFS 迭代随机生成 20×9 迷宫，移动到出口获胜 |
| 3 | **三子棋** | 横屏 | 8×8 棋盘双人对弈，三连即胜，长按落子 |
| 4 | **俄罗斯方块** | 竖屏 | 10×20 标准棋盘，7 种方块 bag 随机，平滑像素下落，DAS 连发 |

## 按键

| 按键 | 引脚 | 大厅 | 飞机大战 | 迷宫 | 三子棋 | 俄罗斯方块 |
|------|------|------|----------|------|--------|------------|
| K1 | PB12 | — | 左移 | 上移 | 上移 | 左移 |
| K2 | PB13 | 上一个 | 右移 | 下移 | 下移 | 右移 |
| K3 | PB14 | 下一个 | 射击 | 左移 | 左移 | 旋转 |
| K4 | PB15 | 进入游戏 | 暂停 | 右移 | 右移/落子 | 暂停 |

大厅图标支持循环滚动，选中项始终居中，左右箭头指示可滚动方向。

## 构建

- **工具链**：Keil MDK v5 (uVision) + ARM Compiler 5 (V5.06 update 7)
- **编译**：打开 `Project.uvprojx` → F7 编译 → F8 烧录 (ULINK2/ST-Link)
- **选项**：`--c99`，宏 `USE_STDPERIPH_DRIVER`
- **输出**：`Objects/Project.hex`（起始 0x08000000，64K Flash）

```
ROM: Code ~14.5KB + RO-data ~2.7KB = ~17.2KB / 64KB
RAM: RW-data ~112B + ZI-data ~3.4KB = ~3.5KB / 20KB
```

## 代码架构

```
Start/       CMSIS 启动 + STM32F10x 设备头文件
Library/     STM32 标准外设库 V3.5.0 (GPIO/RCC/TIM/I2C/FLASH…)
System/      Delay (延时) + Timer (定时器封装)
Hardware/    OLED 驱动、按键消抖、帧缓冲引擎、四款游戏、Flash 存储
User/        main.c 入口
```

核心渲染引擎 `game.c` 管理 1024 字节帧缓冲，横屏 128×64 直接输出，竖屏 64×128 软件 90° 旋转输出。

## v3 → v4 更新日志

### 新增
- **俄罗斯方块**：10×20 标准棋盘，7 种标准方块 (I/O/T/S/Z/J/L)，7-bag 随机
- 平滑像素级下落（每帧 1px，OLED I2C 自然限速约 20fps）
- DAS 左右连发（按住 8 帧后每 3 帧重复移动）
- 旋转带墙踢 (wall kick)，等级加速 (L0 ~1s/格 → L9+ ~0.2s/格)
- **游戏大厅循环滚动**：选中项居中，左右箭头，窗口平滑跟随

### Flash 掉电存储
- STM32 内部 Flash 最后一页 (0x0800FC00) 存储飞机大战 + 俄罗斯方块最高分
- Magic 校验，上电自动加载，破纪录自动写入（禁中断安全操作）

### 按键消抖
- 积分式滞后消抖：每键独立 5 帧计数器，按下/释放均需连续确认
- 大厅导航 8 帧冷却，彻底杜绝双击/抖动连跳
- 完全非阻塞，无 `Delay_ms()` 阻塞调用

### 暂停界面
- 统一清屏显示，去掉棋盘格暗化
- 双线框 + "PAUSED" 居中 + 清晰按键提示 (K4:GO / K1:END)

### 其他优化
- 游戏结束界面统一风格（飞机大战/俄罗斯方块一致）
- 游戏大厅标签居中显示选中游戏名，避免重叠
- 俄罗斯方块 K4 一键暂停/继续（边沿触发）
